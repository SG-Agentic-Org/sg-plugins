# Closure entry — shapes for what closure writes

> Not a file to ship — a reference of the shapes the closure skill writes into the vault.

## Episode (into `inbox.md`)

```
- {{date}} — <one or two lines: the fresh fact from this session>
```

## Decision (into `decisions.md`)

```
## {{date}} — <short title>
- **Decided:** <what>
- **Why:** <reason / alternative rejected>
- **Affects:** <project / area>
```

## Lesson (into `lessons.md`)

```
- **L<N>:** <the rule> — <one line of why>
```

## Entity card (into `people/`, `projects/`, or `cards/`)

Use `card.md`. Check for an existing card (same `id`, then similar title) before creating.
