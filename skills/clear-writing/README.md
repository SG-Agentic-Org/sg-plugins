# clear-writing

Business writing skill based on **"New Rules of Business Correspondence"** by Maxim Ilyakhov & Lyudmila Sarycheva.

**Language:** Russian (the methodology and all templates are in Russian)

## What it does

Three modes:
- **Write** — create business text from scratch based on situation description
- **Edit** — rewrite existing text following the methodology (shows before/after)
- **Review** — give specific recommendations without rewriting

## Topics covered

| Reference file | Topics |
|---------------|--------|
| `references/cold-outreach.md` | Cold emails, proposals, sales letters |
| `references/difficult-replies.md` | Handling complaints, rude emails, conflicts |
| `references/hiring.md` | Job applications, recruiting, speaker invitations |
| `references/internal.md` | Reminders, requests, internal communication, criticism |

## Installation

```bash
cp -r skills/clear-writing ~/.claude/skills/clear-writing
```

## Usage

In Claude Code, just ask to write, edit, or review any business text in Russian. The skill activates automatically.
